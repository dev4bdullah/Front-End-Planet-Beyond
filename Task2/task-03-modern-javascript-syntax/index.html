The parts worth remembering

Feature The bit people get wrong
const locks the binding, not the value — you can still mutate the object
let in a loop each iteration gets its own binding; var shares one
arrow functions no own this — that's the point, not a limitation. Don't use them for object methods that need this
returning an object n => ({ a: n }) — without the parens the braces read as a function body
nested destructuring const { meta: { city } = {} } — the = {} stops a missing parent throwing
?? vs || || rejects 0 and ""; ?? only rejects null and undefined

That last row is the one that causes real bugs. quantity || 1 silently turns a deliberate zero into one. quantity ?? 1 doesn't.
