    Five things this handles that a naive version doesn't
    
        
      
          
    • 
            One key, one object. Not five separate keys. A single read on load, a
            single write on change, and the pieces can never fall out of sync.
          
      • 
          
    • 
            try/catch on both read and write. localStorage genuinely throws — in
            private mode on older Safari, when the quota is full, and when third-party storage is
            blocked. Press Corrupt the storage then refresh: it recovers instead of a white
            screen.
          
      • 
          
    • 
            Spread over defaults on load.
            { ...defaults, ...parsed } means a key you add next week is never
            undefined for someone with old data saved.
          
      • 
          
    • 
            A version number. When the shape changes, old data is migrated rather
            than crashing the app.
          
      • 
          
    • 
            The storage event. Open this page in two tabs and edit one
            — the other notices. Note it fires only in the other tabs, never the one that
            made the change.

          Both store strings only — hence JSON.stringify going in and
          JSON.parse coming out. Both are also synchronous, so writing on every
          keystroke of a large object will block the main thread. Never store tokens, passwords or
          anything sensitive: any script on the page can read it.
