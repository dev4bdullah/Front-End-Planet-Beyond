Reusable Utility Functions

Twenty small helpers in one module, each called live below. Every edge case — an invalid date, an unknown status, division by zero — is exercised on purpose.

The counter climbs on every keypress, but the debounced call only fires 400ms after you stop. That's the difference between one request per keystroke and one per search.

What makes these reusable

  • Pure. Same input, same output, every time. No DOM, no storage, no fetch — so they can't break depending on when you call them.
  • One job each. formatDate formats; it doesn't also decide whether something is overdue. That's isOverdue.
  • Sensible defaults. truncate(text) works without a length, pluralise(n, "task") works without a plural form.
  • Defensive on bad input. formatDate("nonsense") returns "Invalid date" instead of throwing. statusLabel has a fallback. percent(3, 0) returns 0 rather than NaN.
  • Functions that return functions. byKey("hours", "desc") builds a comparator, and debounce(fn) builds a wrapped function — one helper covers every field instead of one per field.
