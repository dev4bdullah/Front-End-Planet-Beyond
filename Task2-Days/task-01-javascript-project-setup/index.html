JavaScript Project Setup

npm scripts, ESLint and Prettier configured for browser ES modules — plus a page that proves the module actually loaded.

Setup check

The commands

Command What it does
npm init -y creates package.json
npm i -D eslint @eslint/js globals the linter and its browser globals
npm i -D prettier eslint-config-prettier formatter, plus the config that stops the two fighting
npm run lint reports problems
npm run format rewrites every file to house style
npm run check lint + format check together, for CI

The two settings that matter

  • "type": "module" in package.json — tells Node and the tooling these are ES modules, not CommonJS. Without it, import is a syntax error to the linter.
  • sourceType: "module" + globals.browser — the same message for ESLint, plus it stops document and window being flagged as undefined.

eslint-config-prettier is last in the ESLint array on purpose. It turns off every stylistic rule that would argue with Prettier, so the two tools never fight over the same line.
