01 — About

A little background

I started with plain HTML and CSS and stayed there long enough to actually understand the box model, the cascade and why semantic elements matter — before reaching for frameworks.

These days I work mostly in React, but the habits from that beginning stuck: keyboard navigation gets tested, headings stay in order, and layouts are built mobile-first rather than squeezed down from a desktop mockup afterwards.

Outside structured work I rebuild things I use daily to see how they're put together — it's the fastest way I've found to learn a pattern properly.
