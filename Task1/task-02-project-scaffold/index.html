Hot reload test

  1. Right-click index.html → Open with Live Server
  2. Check the URL reads 127.0.0.1:5500, not file:///
  3. Open style.css, change --accent to hotpink
  4. Press Ctrl+S — the page recolours without you touching the browser

Boilerplate checklist

  • <!DOCTYPE html> — standards mode, not quirks mode
  • lang="en" on the html tag — screen readers pick the right voice
  • charset="UTF-8" — first thing in the head, so accents render
  • viewport meta — without it, task 4's breakpoints do nothing on phones
  • meta description — what search results show
  • stylesheet linked in the head, not the body
