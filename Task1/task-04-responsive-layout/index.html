Flexbox for the simple rows

Grid is for two-dimensional layout. When items just need to sit in a row and wrap, Flexbox is less code and needs no breakpoints at all — the header nav above is one, and so are these.

The three breakpoints

Mobile-first: base styles apply everywhere, each query adds on top
Query Target Grid becomes
base (no query) under 576px 1 column — everything stacks
min-width: 576px large phones 4 columns
min-width: 768px tablets 6 columns
min-width: 1024px laptops and up all 12 columns

Written mobile-first with min-width, so the smallest screen gets the simplest CSS and never has to undo desktop rules. Task 5 shows how clamp() removes the need for many of these queries entirely.
